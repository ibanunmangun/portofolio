## Documentation status

The current folders are retained as stable case-study paths and historical references. New case-study plans should use a dated filename under the relevant case-study folder, for example:

```text
YYYY-MM-DD-<feature-name>-prd.md
```

Do not move or delete existing documentation solely to normalize naming. Update this index when a case study, route, source boundary, validation path, or documentation location changes.
